# vectorbundles

This project is an attempt to formalize in Lean the classification theorem of vector bundles on (schematic) Fargues-Fontaine curves, following the "elementary" argument given in:
  
  Peter Dillery and Kiran S. Kedlaya, Vector bundles on cones over a Fargues-Fontaine curve.
  
This also doubles as a running example of formalization for my course Math 157: Intro to Mathematical Software (UC San Diego, spring 2026).
