# vectorbundles

This project is an attempt to formalize in Lean the classification theorem for vector bundles on (schematic) Fargues--Fontaine curves. This was used as a running example of formalization for the course Math 157: Intro to Mathematical Software (UC San Diego, spring 2026).

The web version of the blueprint can be found [here](https://kskedlaya.org/vectorbundles/). The dependency graph can be found [here](https://kskedlaya.org/vectorbundles/dep_graph_document.html).
